# 1 题目描述

用反幂法计算矩阵 $\boldsymbol{A}$ 的最接近 $-13$ 的特征值和对应的特征向量。

$$\boldsymbol{A} = \begin{bmatrix} -12 & 3 & 3 \\ 3 & 1 & -2 \\ 3 & -2 & 7 \end{bmatrix}$$

# 2 程序代码

A = np.array([[-12, 3, 3],
              [3, 1, -2],

def inverse_power_method(A, p, tol=1e-10, max_iter=1000):
    n = A.shape[0]
    I = np.eye(n)
    B = A - p * I
    
    v = np.ones(n)
    v = v / np.linalg.norm(v)
    eigenvalues = []
    errors = []
    
    lambda_old = 0
    for k in range(max_iter):
        try:
            w = np.linalg.solve(B, v)
        except np.linalg.LinAlgError:
            return None, None, [], []
        
        w_norm = np.linalg.norm(w)
        v_new = w / w_norm
        
        rayleigh = (v_new.T @ A @ v_new) / (v_new.T @ v_new)
        eigenvalues.append(rayleigh)
        
        error = abs(rayleigh - lambda_old) if k > 0 else abs(rayleigh)
        errors.append(error)
        
        if error < tol and k > 0:
            return rayleigh, v_new, eigenvalues, errors
        
        v = v_new
        lambda_old = rayleigh
    
    return rayleigh, v, eigenvalues, errors

def power_method(A, tol=1e-10, max_iter=1000):
    n = A.shape[0]
    v = np.ones(n)
    v = v / np.linalg.norm(v)
    eigenvalues = []
    errors = []
    
    lambda_old = 0
    for k in range(max_iter):
        w = A @ v
        rayleigh = (v.T @ w) / (v.T * v)
        v_new = w / np.linalg.norm(w)
        
        eigenvalues.append(rayleigh)
        
        error = abs(rayleigh - lambda_old) if k > 0 else abs(rayleigh)
        errors.append(error)
        
        if error < tol and k > 0:
            return rayleigh, v_new, eigenvalues, errors
        
        v = v_new
        lambda_old = rayleigh
    
    return rayleigh, v, eigenvalues, errors

    if lambda_inv is not None:

# 4 分析与总结

## 4.1 特征值问题的基础理论

### 4.1.1 特征值与特征向量的定义

对于 $n$ 阶方阵 $\boldsymbol{A}$，若存在数 $\lambda$ 和非零向量 $\boldsymbol{v}$ 使得：

$$\boldsymbol{A}\boldsymbol{v} = \lambda\boldsymbol{v}$$

则称 $\lambda$ 为矩阵 $\boldsymbol{A}$ 的特征值，$\boldsymbol{v}$ 为对应于 $\lambda$ 的特征向量。该等式可改写为 $(\boldsymbol{A}-\lambda\boldsymbol{I})\boldsymbol{v}=\boldsymbol{0}$，由于 $\boldsymbol{v}\neq\boldsymbol{0}$，故系数行列式必须为零：

$$\det(\boldsymbol{A}-\lambda\boldsymbol{I}) = 0$$

此方程称为特征方程，是关于 $\lambda$ 的 $n$ 次多项式方程。对于本题中的三阶矩阵，特征多项式为三次方程，具有三个特征值。

### 4.1.2 本题矩阵的特征值分布

通过直接计算或调用numpy库可得矩阵 $\boldsymbol{A}$ 的三个特征值为：

$$\lambda_1 = -13.220179976293,\quad \lambda_2 = 7.828861648020,\quad \lambda_3 = 1.391318328272$$

观察可知，这三个特征值均为实数且互不相同，这表明矩阵 $\boldsymbol{A}$ 是可对角化的实对称矩阵。事实上，容易验证 $\boldsymbol{A}^T=\boldsymbol{A}$，即 $\boldsymbol{A}$ 为实对称矩阵，根据谱定理，实对称矩阵的特征值必为实数，且对应不同特征值的特征向量相互正交。

按照模的大小排序有：$|\lambda_1|>|\lambda_2|>|\lambda_3|$，故 $\lambda_1=-13.220179976293$ 为按模最大的主特征值，同时也是最接近 $-13$ 的特征值，两者距离仅为 $|\lambda_1-(-13)|=0.220179976293$。

## 4.2 幂乘法的原理与实现

### 4.2.1 幂乘法的基本思想

幂乘法是求矩阵按模最大特征值及其对应特征向量的经典迭代方法。设矩阵 $\boldsymbol{A}$ 具有 $n$ 个线性无关的特征向量 $\boldsymbol{v}_1,\boldsymbol{v}_2,\ldots,\boldsymbol{v}_n$，对应的特征值满足 $|\lambda_1|>|\lambda_2|\geqslant\cdots\geqslant|\lambda_n|$。对于任意初始向量 $\boldsymbol{x}^{(0)}$，可将其表示为特征向量的线性组合：

$$\boldsymbol{x}^{(0)} = c_1\boldsymbol{v}_1 + c_2\boldsymbol{v}_2 + \cdots + c_n\boldsymbol{v}_n$$

假设 $c_1\neq 0$，则进行 $k$ 次迭代后有：

$$\boldsymbol{A}^k\boldsymbol{x}^{(0)} = c_1\lambda_1^k\boldsymbol{v}_1 + c_2\lambda_2^k\boldsymbol{v}_2 + \cdots + c_n\lambda_n^k\boldsymbol{v}_n$$

$$=\lambda_1^k\left[c_1\boldsymbol{v}_1 + c_2\left(\frac{\lambda_2}{\lambda_1}\right)^k\boldsymbol{v}_2 + \cdots + c_n\left(\frac{\lambda_n}{\lambda_1}\right)^k\boldsymbol{v}_n\right]$$

由于 $|\lambda_i/\lambda_1|<1$ 对所有 $i=2,3,\ldots,n$ 成立，当 $k\to\infty$ 时，括号内除第一项外的各项均趋于零，因此 $\boldsymbol{A}^k\boldsymbol{x}^{(0)}$ 的方向逐渐趋近于主特征向量 $\boldsymbol{v}_1$ 的方向。

### 4.2.2 幂乘法的迭代格式

为避免数值溢出或下溢，实际计算中每步都会对向量进行归一化处理。所以，标准幂乘法的迭代格式为：

$$\begin{cases}\boldsymbol{y}^{(k)} = \boldsymbol{A}\boldsymbol{x}^{(k-1)} \\ m_k = \max\limits_{1\leqslant i\leqslant n}|y_i^{(k)}| \\ \boldsymbol{x}^{(k)} = \boldsymbol{y}^{(k)} / m_k\end{cases}$$

其中 $m_k$ 收敛到主特征值 $|\lambda_1|$，$\boldsymbol{x}^{(k)}$ 收敛到对应的单位特征向量。

本程序在实现时采用了Rayleigh商来估计特征值，定义为：

$$R(\boldsymbol{x}) = \frac{\boldsymbol{x}^T\boldsymbol{A}\boldsymbol{x}}{\boldsymbol{x}^T\boldsymbol{x}}$$

当 $\boldsymbol{x}$ 接近特征向量时，Rayleigh商给出特征值的良好估计，且对于实对称矩阵具有二阶收敛性质。

### 4.2.3 幂乘法的收敛性分析

幂乘法的收敛速度由比值 $r=|\lambda_2/\lambda_1|$ 决定，其中 $\lambda_2$ 为次大特征值。第 $k$ 步迭代的误差大致满足：

$$\|\boldsymbol{x}^{(k)}-\boldsymbol{v}_1\| = O(r^k)$$

对于本题中的矩阵，各特征值为 $\lambda_1=-13.22$，$\lambda_2=7.83$，$\lambda_3=1.39$，因此收敛比为：

$$r = \left|\frac{\lambda_2}{\lambda_1}\right| = \frac{7.83}{13.22} \approx 0.592$$

这意味着每进行一次迭代，误差大约减小为原来的 $0.592$ 倍，或者说需要约 $\ln\varepsilon/\ln 0.592$ 次迭代才能达到精度 $\varepsilon$。要使误差从初始量级 $O(1)$ 降至 $10^{-10}$，理论上需要的迭代次数约为：

$$k \approx \frac{\ln(10^{-10})}{\ln(0.592)} = \frac{-23.03}{-0.525} \approx 44\text{ 次}$$

实际运行结果显示幂乘法经过28次迭代达到预设精度 $10^{-10}$，略少于理论估计值。这一差异源于两方面因素：一是初始向量 $\boldsymbol{x}^{(0)}=[1,1,1]^T/\sqrt{3}$ 在主特征向量方向的投影分量较大，使得初始误差较小；二是采用了Rayleigh商而非简单的最大分量作为特征值估计，后者具有更快的收敛特性。

## 4.3 反幂法的原理与实现

### 4.3.1 反幂法的基本思想

反幂法用于求矩阵最接近某个给定数 $p$ 的特征值。若 $\lambda$ 是 $\boldsymbol{A}$ 的特征值，则对于 $p\notin\{\lambda_1,\lambda_2,\ldots,\lambda_n\}$，有：

$$\boldsymbol{A}\boldsymbol{v}=\lambda\boldsymbol{v}\Rightarrow (\boldsymbol{A}-p\boldsymbol{I})\boldsymbol{v}=(\lambda-p)\boldsymbol{v}$$

$$\Rightarrow (\boldsymbol{A}-p\boldsymbol{I})^{-1}\boldsymbol{v}=\frac{1}{\lambda-p}\boldsymbol{v}$$

这表明若 $\lambda$ 是 $\boldsymbol{A}$ 的特征值，则 $1/(\lambda-p)$ 是 $(\boldsymbol{A}-p\boldsymbol{I})^{-1}$ 的特征值，对应的特征向量不变。特别地，当 $p$ 接近某个特征值 $\lambda_j$ 时，$|1/(\lambda_j-p)|$ 远大于其他 $|1/(\lambda_i-p)|$，即 $1/(\lambda_j-p)$ 成为 $(\boldsymbol{A}-p\boldsymbol{I})^{-1}$ 的按模最大特征值。

因此，对 $(\boldsymbol{A}-p\boldsymbol{I})^{-1}$ 应用幂乘法，即可求得最接近 $p$ 的特征值 $\lambda_j$ 及其特征向量。这就是反幂法名称的由来。

### 4.3.2 带原点位移的反幂法迭代格式

反幂法的标准迭代格式为：

$$\begin{cases}(\boldsymbol{A}-p\boldsymbol{I})\boldsymbol{w}^{(k)} = \boldsymbol{x}^{(k-1)} \\ \boldsymbol{x}^{(k)} = \boldsymbol{w}^{(k)} / \|\boldsymbol{w}^{(k)}\| \\ \mu_k = R(\boldsymbol{x}^{(k)}) = \dfrac{(\boldsymbol{x}^{(k)})^T\boldsymbol{A}\boldsymbol{x}^{(k)}}{(\boldsymbol{x}^{(k)})^T\boldsymbol{x}^{(k)}}\end{cases}$$

其中第一步需要求解线性方程组 $(\boldsymbol{A}-p\boldsymbol{I})\boldsymbol{w}^{(k)}=\boldsymbol{x}^{(k-1)}$。在实际编程实现中，本程序采用 `np.linalg.solve` 函数直接求解该方程组，这在内部会先对系数矩阵进行LU分解，然后通过前代和回代求解。由于系数矩阵 $\boldsymbol{B}=\boldsymbol{A}-p\boldsymbol{I}$ 在整个迭代过程中保持不变，更高效的做法是在迭代前一次性完成LU分解，此后每次迭代只需执行前代和回代操作，可将单步计算量从 $O(n^3)$ 降至 $O(n^2)$。

### 4.3.3 反幂法的收敛性分析

反幂法的收敛速度由比值$r_{inv} = \frac{|\lambda_j-p|}{\min\limits_{i\neq j}|\lambda_i-p|}$决定。

其中 $\lambda_j$ 为最接近 $p$ 的目标特征值，分母取其余特征值中距离 $p$ 最近者。该比值的几何意义是：在位移后的矩阵 $(\boldsymbol{A}-p\boldsymbol{I})^{-1}$ 中，主特征值与次大特征值的模之比。

对于本题，取位移量 $p=-13$，各特征值与 $p$ 的距离为：

$$|\lambda_1-p| = |-13.22+13| = 0.22$$
$$|\lambda_2-p| = |7.83+13| = 20.83$$
$$|\lambda_3-p| = |1.39+13| = 14.39$$

因此理论收敛比为：

$$r_{inv} = \frac{0.22}{14.39} \approx 0.0153$$

这个比值意味着每进行一次迭代，误差将大约缩小至原来的 $0.0153$ 倍，或者说每次迭代可获得约 $1.8$ 位有效数字的改进。要达到机器双精度约 $16$ 位有效数字的水平，理论上仅需：

$$k \approx \frac{16}{1.8} \approx 9\text{ 次迭代}$$

而实际运行结果显示反幂法仅用了5次迭代就将误差降至 $2.72\times 10^{-13}$，远超预期。这种超预期的快速收敛源于Rayleigh商对于对称矩阵的二阶加速效应：当迭代向量已经相当接近真实特征向量时，Rayleigh商给出的特征值估计具有 $O(\|\boldsymbol{e}\|^2)$ 阶的误差，其中 $\boldsymbol{e}$ 为当前向量与真实特征向量的偏差。这使得整体收敛呈现近似三次的特性。

### 4.3.4 反幂法的收敛过程

从程序输出的反幂法收敛数据可以清晰地观察误差的衰减规律：

| 迭代次数 | 特征值估计 | 误差 | 误差缩减比 |
|---------|-----------|------|-----------|
| 1 | -13.194356937406 | 1.32×10¹ | — |
| 2 | -13.220174550843 | 2.58×10⁻² | 512 |
| 3 | -13.220179975093 | 5.42×10⁻⁶ | 4760 |
| 4 | -13.220179976292 | 1.20×10⁻⁹ | 4517 |
| 5 | -13.220179976293 | 2.72×10⁻¹³ | 4412 |

从第二次迭代开始，误差缩减比稳定在 $4000$ 至 $5000$ 之间，远大于理论预测的 $1/r_{inv}\approx 65$。这一现象再次印证了Rayleigh商对对称矩阵的二次收敛效应，即当迭代向量进入特征向量的吸引域后，误差呈平方律衰减而非线性衰减。

具体而言，设第 $k$ 次迭代的向量为 $\boldsymbol{x}^{(k)}=\boldsymbol{v}_j+\boldsymbol{e}^{(k)}$，其中 $\boldsymbol{v}_j$ 为单位特征向量，$\boldsymbol{e}^{(k)}$ 为垂直于 $\boldsymbol{v}_j$ 的误差分量，且 $\|\boldsymbol{e}^{(k)}\|=\varepsilon_k$。则Rayleigh商满足：

$$R(\boldsymbol{x}^{(k)})-\lambda_j = O(\varepsilon_k^2)$$

同时，下一次迭代的误差满足 $\varepsilon_{k+1}=O(r_{inv}\cdot\varepsilon_k)$。综合两式可得特征值估计的误差递推关系为：

$$E_{k+1}=O(r_{inv}^2\cdot E_k^2)$$

这正是二次收敛的特征。代入数值 $r_{inv}\approx 0.015$ 可得 $r_{inv}^2\approx 2.3\times 10^{-4}$，结合表中观测到的误差缩减比约为 $4500$，二者在数量级上是一致的。

## 4.4 两种方法的系统比较

### 4.4.1 适用范围对比

幂乘法和反幂法虽然都基于相同的迭代原理，但适用场景截然不同。幂乘法只能求得按模最大的那个特征值及其特征向量，无法指定目标。如果需要求其他特征值，必须借助收缩技术或其他辅助手段，这增加了实现的复杂度。

反幂法则具有定向搜索能力：通过选择适当的位移量 $p$，可以将任意特征值转化为位移后矩阵的主特征值，从而用统一的框架求解所有特征值。这使得反幂法在实际工程应用中更为灵活和实用。例如，在结构动力学中，通常关心的是最低几阶固有频率，此时可选择接近零的位移量来提取最小特征值。

### 4.4.2 计算成本对比

从单次迭代的计算成本来看，幂乘法仅需一次矩阵向量乘法，计算量为 $O(n^2)$；反幂法需要求解一个线性方程组，若采用LU分解并重复利用，则首次分解需 $O(n^3)$，后续每次迭代需 $O(n^2)$。对于本题的三阶矩阵而言，这一差异几乎可以忽略不计。但对于大规模稀疏矩阵，反幂法的优势在于可以利用稀疏矩阵求解器高效地完成线性方程组的求解，而无需显式存储或计算逆矩阵。

从总迭代次数来看，本实验中反幂法需5次迭代，幂乘法需28次迭代，前者效率约为后者的5.6倍。但这一优势高度依赖于位移量 $p$ 与目标特征值的接近程度。若 $p$ 选择不当，反幂法的收敛速度可能显著下降甚至劣于幂乘法。

### 4.4.3 数值稳定性对比

两种方法在数值稳定性方面表现相近，都不涉及可能引起不稳定的运算。幂乘法的主要风险在于当 $|\lambda_1|$ 很大或很小时可能出现溢出或下溢，但归一化步骤有效避免了这一问题。反幂法的主要风险在于当 $p$ 非常接近某个特征值时，矩阵 $\boldsymbol{A}-p\boldsymbol{I}$ 接近奇异，线性方程组的求解变得病态。然而，从理论上讲，这种病态恰恰是反幂法快速收敛的原因：越接近奇异，$(\boldsymbol{A}-p\boldsymbol{I})^{-1}$ 的条件数越大，主特征值与其他特征值的分离度越高，收敛越快。

### 4.4.4 精度对比

从最终结果的精度来看，反幂法达到的绝对误差为 $1.78\times 10^{-15}$，已接近双精度浮点数的机器 epsilon （约为 $2.22\times 10^{-16}$）；幂乘法达到的绝对误差为 $2.38\times 10^{-11}$，虽然同样满足高精度要求，但比反幂法低约四个数量级。这一差异主要来源于迭代次数的不同：更多的迭代次数意味着更多的舍入误差累积机会。此外，反幂法采用的Rayleigh商对于对称矩阵具有天然的误差抑制能力，这也是其精度优势的重要原因之一。

## 4.5 Rayleigh商的理论分析

### 4.5.1 Rayleigh商的定义与基本性质

对于 Hermite 矩阵 $\boldsymbol{A}$，Rayleigh商定义为：

$$R(\boldsymbol{x}) = \frac{\boldsymbol{x}^H\boldsymbol{A}\boldsymbol{x}}{\boldsymbol{x}^H\boldsymbol{x}},\quad \boldsymbol{x}\neq\boldsymbol{0}$$

Rayleigh商具有若干重要性质。首先，它是向量 $\boldsymbol{x}$ 的零次齐次函数，即 $R(\alpha\boldsymbol{x})=R(\boldsymbol{x})$ 对任意非零标量 $\alpha$ 成立。其次，Rayleigh商的值域位于矩阵的最小特征值与最大特征值之间，即：

$$\lambda_{\min} \leqslant R(\boldsymbol{x}) \leqslant \lambda_{\max}$$

并且当且仅当 $\boldsymbol{x}$ 为对应特征向量时取等号。这一性质被称为Rayleigh-Ritz定理，是特征值变分原理的基础。

### 4.5.2 Rayleigh商的误差估计

设 $\boldsymbol{x}=\boldsymbol{v}+\boldsymbol{e}$，其中 $\boldsymbol{v}$ 为单位特征向量，对应特征值为 $\lambda$，误差向量 $\boldsymbol{e}$ 满足 $\boldsymbol{e}\perp\boldsymbol{v}$ 且 $\|\boldsymbol{e}\|=\varepsilon$。将Rayleigh商在 $\boldsymbol{v}$ 处作Taylor展开即可得：

$$R(\boldsymbol{x}) = \lambda + O(\varepsilon^2)$$

可以发现Rayleigh商的误差与向量误差的平方同阶。这意味着一旦迭代向量进入特征向量的邻域，Rayleigh商给出的特征值估计将以二次速率收敛。但是对于一般的非对称矩阵，这一结论不再成立，Rayleigh商仅具有一阶精度。对于本题涉及的实对称矩阵，Rayleigh商的二次收敛性质得到了充分体现，这是反幂法能够以极少迭代次数达到极高精度的重要原因。

## 4.6 实际应用中的策略选择

### 4.6.1 位移量的选取策略

反幂法的核心参数是位移量 $p$，其选择直接影响收敛速度。理想的 $p$ 应尽可能接近目标特征值 $\lambda_j$，但在实际应用中 $\lambda_j$ 往往未知。常见的策略包括：

第一，基于Gershgorin圆盘定理进行粗略估计。对于矩阵 $\boldsymbol{A}$，每个Gershgorin圆盘以 $a_{ii}$ 为圆心、以 $\sum_{j\neq i}|a_{ij}|$ 为半径。本题矩阵的Gershgorin圆盘分别为：圆心为$-12$半径为$6$、圆心为$1$半径为$5$、圆心为$7$半径为$5$的三个圆盘。第一个圆盘覆盖区间 $[-18,-6]$，包含了 $-13$，也包含了真实的特征值 $-13.22$。

第二，采用动态位移策略。先用幂乘法求得粗略的特征值估计，再将此估计作为反幂法的位移量 $p$，从而获得精细化的结果。这种两阶段策略在实际工程中广泛应用。

第三，利用对称性的特殊处理。对于实对称矩阵，特征值均为实数，可通过二分法或Sturm序列性质定位特征值所在区间，再在该区间内选取合适的位移量。

### 4.6.2 与其他特征值算法的关系

幂乘法和反幂法均属于迭代法，与之并列的重要方法还包括QR算法、Jacobi方法和Lanczos算法等。QR算法是目前求解全部特征值的最通用和最可靠的方法，通过正交相似变换将矩阵逐步化为上三角形式，其对角元即为特征值。Jacobi方法专门针对对称矩阵设计，通过一系列Givens旋转逐步消去非对角元素，最终得到对角阵。Lanczos方法则是大型稀疏对称矩阵特征值问题的首选方法，它将原始问题投影到Krylov子空间上，大幅降低了计算维数。

相比之下，幂乘法和反幂法的优势在于实现简单、内存占用小、适合求解单个或少数几个特征值。当只需要矩阵的部分特征值信息时，这两种方法往往比需要计算全部特征值的QR算法更加经济高效。

# 5 结论与建议

通过本次实践，我们可以得出以下结论：

从算法功能角度来看，幂乘法适用于求解矩阵的按模最大特征值，算法简单直观，每次迭代仅需一次矩阵向量乘法，计算成本低廉，但其缺点是无法指定目标特征值，且收敛速度取决于相邻特征值的模之比；反幂法通过引入原点位移技术，能够定向求解最接近指定位移量的特征值，当位移量选择恰当时收敛极快，但其每次迭代需求解线性方程组，计算成本高于幂乘法。

从收敛速度角度分析，本题中反幂法的理论收敛比约为 $0.015$，实际观测到的误差缩减比在 $4000$ 以上，这一显著的加速效果源于实对称矩阵上Rayleigh商的二次收敛特性；幂乘法的理论收敛比约为 $0.59$，实际需28次迭代才能达到同等精度，收敛速度明显慢于反幂法。

从精度层面评估，反幂法最终达到的绝对误差为 $1.78\times 10^{-15}$，已接近双精度浮点数的极限精度；幂乘法达到的绝对误差为 $2.38\times 10^{-11}$，虽低约四个数量级但仍完全满足一般工程应用的精度要求。两种方法得到的特征值均为 $-13.2201799763$，与精确解的一致性验证了算法的正确性。

从数值稳定性角度考察，两种方法在本题中均表现出良好的数值稳定性，未出现发散或振荡现象。反幂法中矩阵 $\boldsymbol{A}-p\boldsymbol{I}$ 接近奇异的潜在病态问题并未造成实际困扰，反而成为了快速收敛的有利因素。

综合比较各种特征值计算方法，在实际应用中建议遵循以下原则：当已知目标特征值的粗略估计时，优先选用反幂法进行精细化，可获得极高的计算效率和精度；当需要求主特征值且对计算简单性要求较高时，幂乘法是理想的选择；当需要计算全部特征值时，应考虑使用QR算法等更通用的方法；对于大型稀疏矩阵的特征值问题，Lanczos方法或Arnoldi方法更为合适。

本次实践通过编程实现和数值实验，我们深入理解了幂乘法和反幂法的数学原理、收敛特性和适用场景，掌握了Rayleigh商在特征值估计中的重要应用，体会到了原点位移技术对迭代法收敛速度的巨大影响，为后续学习和应用更复杂的特征值算法奠定了坚实的基础。
