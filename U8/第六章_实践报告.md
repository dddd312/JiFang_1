- `detailed_analysis()`函数：进行详细的误差分析和收敛性分析

"""
Romberg数值积分算法实现
用于计算方法第六章实践题目第二题
"""

import math

def romberg(f, a, b, n=10, tol=1e-12):
    """
    使用Romberg算法计算定积分 ∫_a^b f(x) dx
    
    参数:
        f: 被积函数，接受一个浮点数参数
        a, b: 积分下限和上限
        n: 最大迭代次数（默认10）
        tol: 收敛容差（默认1e-12）
    
    返回:
        integral: 积分近似值
        table: Romberg表（二维列表）
    """
    # 初始化Romberg表，table[i][j] 对应 R(i,j)
    table = [[0.0 for _ in range(n+1)] for _ in range(n+1)]
    
    # 第一步：计算R(0,0) = (b-a)/2 * [f(a) + f(b)]
    h = b - a
    table[0][0] = h * 0.5 * (f(a) + f(b))
    
    # 迭代计算
    for i in range(1, n+1):
        # 步长减半
        h *= 0.5
        
        # 计算复化梯形公式 R(i,0)
        # 首先计算新增节点的函数值之和
        total = 0.0
        for k in range(1, 2**(i-1) + 1):
            x = a + (2*k - 1) * h
            total += f(x)
        
        # R(i,0) = 0.5 * R(i-1,0) + h * total
        table[i][0] = 0.5 * table[i-1][0] + h * total
        
        # Richardson外推
        for j in range(1, i+1):
            factor = 4.0**j
            table[i][j] = (factor * table[i][j-1] - table[i-1][j-1]) / (factor - 1.0)
        
        # 检查收敛性：如果 |R(i,i) - R(i-1,i-1)| < tol，则提前终止
        if i > 0 and abs(table[i][i] - table[i-1][i-1]) < tol:
            # 只保留前i+1行
            table = [row[:i+1] for row in table[:i+1]]
            break
    
    return table[-1][-1], table

# 4 分析与总结

## 4.1 Romberg算法原理与Richardson外推

Romberg算法是基于梯形公式和Richardson外推技术的高精度数值积分方法。其核心思想是通过逐步细分区间并应用外推公式消除低阶误差项。

### 4.1.1 梯形公式及其误差

复合梯形公式将积分区间 $[a, b]$ 分为 $n$ 等份，步长 $h = \frac{b-a}{n}$，计算公式为：
$$
T(h) = \frac{h}{2} \left[ f(a) + 2\sum_{i=1}^{n-1} f(a+ih) + f(b) \right]
$$

梯形公式的截断误差可表示为：
$$
I - T(h) = c_1 h^2 + c_2 h^4 + c_3 h^6 + \cdots
$$
其中 $c_1, c_2, c_3, \dots$ 是与被积函数导数有关的常数。

### 4.1.2 Richardson外推

设 $T(h)$ 和 $T(h/2)$ 分别为步长 $h$ 和 $h/2$ 的梯形公式近似值。根据误差展开式：
$$
\begin{aligned}
I &= T(h) + c_1 h^2 + c_2 h^4 + \cdots \\
I &= T(h/2) + c_1 (h/2)^2 + c_2 (h/2)^4 + \cdots
\end{aligned}
$$

消去 $h^2$ 项，得到改进的近似值：
$$
S(h) = \frac{4T(h/2) - T(h)}{4 - 1} = T(h/2) + \frac{T(h/2) - T(h)}{3}
$$
$S(h)$ 的误差阶为 $O(h^4)$，这实际上是Simpson公式。

### 4.1.3 Romberg算法递推公式

推广上述过程，定义 $R_{k,0}$ 为步长 $h_k = \frac{b-a}{2^k}$ 的梯形公式近似值。外推公式为：
$$
R_{k,m} = \frac{4^m R_{k,m-1} - R_{k-1,m-1}}{4^m - 1}, \quad k = 1,2,\dots, \quad m = 1,2,\dots,k
$$

其中：
- $R_{k,0}$：步长 $h_k$ 的梯形公式结果
- $R_{k,1}$：误差阶 $O(h^4)$（Simpson公式）
- $R_{k,2}$：误差阶 $O(h^6)$
- $R_{k,m}$：误差阶 $O(h^{2m+2})$

## 4.2 收敛性分析与误差估计

### 4.2.1 收敛速度

从运行结果可以看出，Romberg算法具有超线性收敛速度。对于积分1：
- 第1次外推：误差 $9.22\times10^{-2}$，误差比 3.79
- 第2次外推：误差 $6.14\times10^{-3}$，误差比 15.03
- 第3次外推：误差 $8.70\times10^{-5}$，误差比 70.49
- 第4次外推：误差 $4.88\times10^{-8}$，误差比 1785.30

误差比逐渐增大，表明收敛速度在加快。理论上，$R_{k,m}$ 的误差阶为 $O(h^{2m+2})$，当 $h$ 减半时，误差大约减少 $2^{-(2m+2)}$。

### 4.2.2 算法终止条件

程序设置了两个终止条件：
1. 最大迭代次数 $n$，默认为10
2. 收敛容差 $tol$，默认为 $10^{-12}$

当对角线元素满足 $|R_{k,k} - R_{k-1,k-1}| < tol$ 时，算法提前终止。

### 4.2.3 数值稳定性

Romberg算法在数值上是稳定的，原因如下：
1. 递推公式中的系数 $4^m/(4^m-1)$ 随着 $m$ 增大趋近于1，不会引起数值溢出
2. 梯形公式本身是数值稳定的积分方法
3. 对于光滑函数，外推过程不会放大舍入误差

## 4.3 与其它数值积分方法比较

### 4.3.1 与简单梯形公式比较

简单梯形公式（$n=1$）的结果：
- 积分1：$T = 0.0732625556$，相对误差 82.7%
- 积分2：$T = -0.3926990817$，相对误差 13.3%

Romberg算法通过外推将误差降低了多个数量级，体现了其高精度特性。

### 4.3.2 与Simpson公式比较

Simpson公式对应 Romberg表中的 $R_{k,1}$，误差阶为 $O(h^4)$。由运算结果可以看出：Romberg算法通过多次外推可以获得更高阶的近似值。

### 4.3.3 与高斯积分比较

高斯积分使用最优节点和权重，对于光滑函数可以达到指数收敛速度。而与高斯积分相比，Romberg算法的优势在于：
1. 不需要计算正交多项式的根
2. 自适应性强，易于实现
3. 对于一般光滑函数，收敛速度足够快

## 4.4 被积函数特性对算法的影响

### 4.4.1 光滑性要求

Romberg算法要求被积函数在积分区间上充分光滑，即足够阶导数连续。本实验中的两个函数都满足这一条件：
- $f_1(x) = x^2 e^{-x^2}$：在 $[0, 2]$ 上无限次可微
- $f_2(x) = \cot x$：在 $[\pi/2, 3\pi/4]$ 上可微，但在 $x=0$ 处有奇点，由于其不在积分区间内，忽略。

### 4.4.2 积分2的解析解验证

积分 $\int \cot x dx = \ln|\sin x| + C$，因此：
$$
I_2 = \int_{\pi/2}^{3\pi/4} \cot x dx = \ln\left|\sin\frac{3\pi}{4}\right| - \ln\left|\sin\frac{\pi}{2}\right| = \ln\frac{\sqrt{2}}{2} - \ln 1 = \ln\frac{\sqrt{2}}{2} \approx -0.346573590279973
$$

程序计算结果与解析解高度一致，绝对误差仅为 $1.11\times10^{-16}$，精度较高。

### 4.4.3 积分1的误差估计

由于积分1没有简单的解析表达式，我们使用高精度Romberg结果，即$n=20$时的Romberg结果作为参考值。计算结果显示，标准Romberg结果（$n=10$）与高精度结果的差异在 $10^{-12}$ 量级以下，表明算法已经收敛到机器精度附近。

# 5 结论与建议

通过本次实践，我们可以得出以下结论：

从算法精度来看，Romberg算法通过Richardson外推技术显著提高了数值积分精度，对于积分2，计算结果与解析解的绝对误差仅为 $1.11\times10^{-16}$，达到了机器精度水平；从收敛速度角度分析，两个积分分别在8-9次迭代后收敛，误差比随着迭代次数增加而增大，表明算法具有超线性收敛特性，理论上$m$次外推可将误差阶提高到$O(h^{2m+2})$；从计算效率评价，与简单梯形公式相比，Romberg算法在增加少量计算量的情况下将精度提高了多个数量级，自适应终止条件进一步优化了计算效率；就数值稳定性而言，递推公式设计合理且系数有界，对于光滑函数不会出现数值不稳定现象。

综合比较各种数值积分方法，Romberg算法在保证高精度的前提下具有良好的计算效率，适合被积函数足够光滑且需要高精度结果的工程计算；而梯形公式和Simpson公式简单易实现但精度较低，适合快速估算；高斯积分在节点数相同时精度最高但需要计算正交多项式根；自适应积分更适合处理奇点或不连续点。在实际应用中，对于一般工程计算，Romberg算法是精度和效率的较好平衡，建议设置合理的容差（如$10^{-8}$到$10^{-12}$）和最大迭代次数（如10-15），对于非光滑函数或有奇点的积分，应考虑其他方法或进行区间划分。
