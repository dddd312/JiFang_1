# 第六章实践题目

**下列题目任选其一，也可以自己寻找感兴趣的问题进行实践检验！**

1.  分别用复化Simpson公式和变步长梯形公式算法，编制程序，计算如下列积分并比较分析运算结果．

> (1)$I = \int_{0}^{1}\frac{1}{1 + x^{2}}dx$ (2)$I = \int_{0}^{1}\frac{\sin x}{x}dx$

2.  用Romberg算法，编制程序，计算如下列积分，并比较分析运算结果．

> (1)$I = \int_{0}^{2}{x^{2}e^{- x^{2}}}dx$ (2)$I = \int_{\pi/2}^{3\pi/4}{\cot x}dx$

3.  用数值微分公式，编制程序，计算$f(x) = e^{x}$在$x = 1$处的导数值，并比较分析运算结

果，探讨步长的选取方法以及需要注意的事项．
