# 第七章实践题目

**下列题目任选其一，也可以自己寻找感兴趣的问题进行实践检验！**

1.  用显式、隐式Euler公式求解常微分方程初值问题

``` math
\left\{ \begin{array}{r}
y' = y - \frac{2x}{y},0 < x \leq 1, \\
y(0) = 1,
\end{array} \right.\ 
```

取步长$h = 0.1$，隐式求解时$\varepsilon = 10^{- 7}$，观察过程中的误差变化，并将两种方法的最终解与误差对比分析。（理论解为$y(x) = \sqrt{1 + 2x}$）。也可以取不同步长观察误差变化情况。

2.  分别用Euler预估-校正方法、经典的四阶Runge-Kutta方法、四阶Adams预估-校正方法，编制程序，计算如下微分方程，并取不同步长比较分析运算结果．

``` math
\left\{ \begin{aligned}
 & y' = - xy^{2}\quad 0 \leq x \leq 5 \\
 & y(0) = 2
\end{aligned} \right.\ 
```

3.  用经典的四阶Runge-Kutta方法，编制程序，计算如下微分方程组，并取不同步长比

> 较分析运算结果，并绘出解的图形．

``` math
\left\{ \begin{aligned}
 & y_{1}' = y_{1}(4 - 0.0003y_{1} - 0.0004y_{2}) \\
 & y_{2}' = y_{2}(2 - 0.0002y_{1} - 0.0001y_{2}) \\
 & y_{1}(0) = y_{2}(0) = 10000
\end{aligned} \right.\ \quad 0 \leq x \leq 10
```
